# Lulu template intake

The official **US Trade 6 x 9 Word interior template** is retained here as
`lulu-us-trade-interior-template.dotx`. It is the design authority for the
Pandoc DOCX build; commit the exact vendor binary so every contributor uses the
same layout.

The final cover template must be downloaded only after the interior PDF’s page
count is fixed, because Lulu calculates the spine width from that count.

- Target: paperback, US Trade 6 x 9, Color Standard interior
- Artwork: sRGB, 300 ppi minimum
- Safety margin: 0.5 in; full-bleed document: 6.25 x 9.25 in
