# When One Agent Is Not Enough

## Intuition

Multiple agents add specialization and review, but also coordination cost and
new failure modes.

## Problem

Evaluate a deterministic workflow, one planner, and a researcher/critic/writer
graph against the same book-maintenance request.

## Minimal implementation

The companion system will make the handoffs and shared state visible.

## Experiment

Compare a deterministic workflow, a single agent, and a multi-agent graph.

## What broke

Record duplicated work, bad delegation, and conflicting recommendations.

## Alternatives and takeaway

More agents are justified only when the task benefits from specialization.
