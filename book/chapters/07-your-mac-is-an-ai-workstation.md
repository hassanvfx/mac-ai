# Your Mac Is an AI Workstation

## Intuition

Unified memory changes how local model size, quantization, and throughput relate.

## Problem

Compare PyTorch MPS, MLX, and MLX-LM for local inference on Apple Silicon.

## Minimal implementation

The companion benchmark will use one prompt, declared model versions, and
repeatable timing.

## Experiment

Measure tokens per second, memory behavior, and quantization trade-offs.

## What broke

Record model-loading, quantization, and compatibility failures.

## Alternatives and takeaway

Local inference is a systems decision, not only a privacy preference.
