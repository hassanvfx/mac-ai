# The Transformer Changed Everything

## Intuition

Attention lets each token select useful context rather than receiving a fixed
summary of a sequence.

## Problem

Move from tokenization to a pretrained model inference path we can inspect.

## Minimal implementation

The companion code will expose tokenizer inputs, attention masks, and outputs.

## Experiment

Compare manual inference with a high-level pipeline.

## What broke

Record context limits, token surprises, and device-memory constraints.

## Alternatives and takeaway

Transformers trade recurrent sequence processing for flexible context mixing.
