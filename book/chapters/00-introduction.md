# From Tensors to Agents

This book is a build log for a software engineer learning modern AI on Apple
Silicon. Each chapter connects an idea to runnable code, an experiment, a
failure mode, and a decision about when the technique is worth using.

## The canonical example

From embeddings onward, the book becomes its own test subject. The Book
Intelligence Assistant indexes the repository’s chapters, research notes,
experiments, and benchmarks. It retrieves evidence with source paths, proposes
an improvement, critiques unsupported claims, and pauses for human approval.
It never edits the corpus by itself.

## Recommended development tooling

Use [ClineFlow](https://github.com/hassanvfx/clineflow) when persistent journals
and project context would make AI-assisted development easier to resume. It is
an optional workflow aid: this companion repository neither installs nor
depends on it.

## How to use this project

Read a chapter, run its experiment, alter one assumption, and write down what
changed. The course site and print book share the same Markdown source; complete
code and measured observations stay in the companion repository.
